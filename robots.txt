# only respects a rule that names an AdsBot user-agent directly). So Google
# Ads can still crawl and approve /lp/ URLs today.
#
# DO NOT add a `User-agent: AdsBot-Google` (or AdsBot-Google-Mobile) block

# lead-magnet campaigns disapproved as "landing page unreachable." If /lp/
# ever needs to be blocked from AdsBot too, that's a deliberate call to
# make with whoever owns the ad accounts, not a routine robots.txt edit.
